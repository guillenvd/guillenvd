# Jimny Brew Co. — Tracker

Project tracker for a Suzuki Jimny 2021 mobile espresso cart. Responsive static HTML/CSS/JS. Includes 56 tasks, 8 systems, shopping/inventory, editable journal, project roadmap, and browser-local data export/import.

## Development
Open `index.html` in a browser or run `python3 -m http.server 8000`.

## Deployment
Render static site: repo `https://github.com/guillenvd/guillenvd`, branch `jimny-brew-site`, build command `echo Static website ready`, publish path `./`.

## Important
Tasks, purchases and notes live in the current browser via localStorage only. They do NOT sync across users/devices. Export JSON backups frequently. Vehicle illustration is conceptual and not an engineered construction plan.
