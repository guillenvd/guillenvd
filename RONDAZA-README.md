# Rondaza v17.2

Prototipo estático de Rondaza, publicado independientemente de v15.

Características: tarjetas de fidelidad configurables por sucursal o compartidas entre sucursales, menú general o por sede, granos y métodos de preparación, eventos y roles demo.

Nota: este prototipo utiliza almacenamiento local del navegador, sin API, autenticación ni datos en servidor. No es un sistema productivo de recompensas.
